# DEB-hypoxia-stickleback
DEB model to investigate the effects of temperature and dissolved oxygen on energy allocation, development and life-history traits of the freshwater three spined stickleback.

This model requires DEBtool MATLAB extension to run (available at https://github.com/add-my-pet/DEBtool_M).

This repository contains:
1) mydata: model data
2) pars_init: initial parameter values for model estimation/simulation
3) predict: model equations
4) run: sets routine parameters
5) folder with calibration results for the three spined stickleback
